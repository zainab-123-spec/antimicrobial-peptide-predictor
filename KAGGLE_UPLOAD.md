# How to put this on your Kaggle profile (10 minutes)

1. Go to https://www.kaggle.com/code and click **New Notebook**, then **File, Import Notebook**.
2. Upload `kaggle/antimicrobial-peptide-esm2-kaggle.ipynb`.
3. In the right panel, open **Settings** and turn **Internet** on. You may need to verify your phone number once. CPU is enough, no GPU needed.
4. Click **Run All**. It takes about 3-5 minutes. Check that the numbers match the README (AUC about 0.975 for ESM-2).
5. Click **Save Version**, choose **Save & Run All (Commit)**, then set the notebook to **Public**.
6. Title: `Antimicrobial Peptide Prediction: ESM-2 vs Classic Features`.
   Tags: `biology`, `healthcare`, `classification`, `deep learning`, `nlp`.
7. Add the GitHub link in the first markdown cell if your username differs.
8. Optional: also upload the 6 FASTA files as a Kaggle **Dataset** (cite Veltri et al. 2018,
   GPL-3.0), so others can use it with Internet off.

Do not claim the published numbers as yours. The notebook prints them as a reference.
